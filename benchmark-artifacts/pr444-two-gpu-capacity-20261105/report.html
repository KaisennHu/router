两卡 C16：KV 容量对照

两个容量各对三种策略运行一次，使用同一对 B300、同一 workload 和软件版本。结果是探索性观测，不证明因果或重复性。

AgentX 32 sessions × 4 个原始请求，128 请求、5,296,896 input / 39,508 output tokens；最长原始输出 847 token，无裁剪。同 agent 间隔缩放为 0，token ID 根据每个 session 的源 hash 重建，不包含跨 session 前缀共享。

Qwen3-4B-Instruct-2507、BF16、TP1、max model length 196,608、max batched tokens 8,192、每 worker 最多 16 个序列，HOST 关闭；Cache 使用 0.3/64/1.5 默认阈值。每组 worker 和 Router 预热，worker 前缀缓存重新清空；性能组不启用诊断埋点。

Cache：cache-aware；KV：kv-aware；P：prefill progress。每组 128/128 请求成功，逐请求和全部 worker 指标保存在各运行目录。
