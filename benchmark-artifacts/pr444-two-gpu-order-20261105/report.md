# 两卡 C16：回放顺序对照

两组使用同一对 B300、同一批 32 个 AgentX session 和同一软件版本，每种策略各运行一次。改变 AgentInfer sample seed 会改变任务顺序和其他 seed 派生输入；它不是同一到达轨迹的重复实验。

128 个请求、5,296,896 input / 39,508 output tokens；最长原始输出 847 token、无裁剪。两个 worker 每个 96 GiB HBM KV，HOST 关闭，C16；相同模型、批处理配置和 Cache 默认阈值。token ID 根据 session 内源 hash 重建，不含跨 session 共享。

seed 0 的首批 16 个 session 中 4 个首请求是长 prefill，seed 1 中为 6 个。seed 1 在运行前固定，目的是观察初始长请求重叠较多时的表现；这些结果不可代表全部 AgentX 场景。
