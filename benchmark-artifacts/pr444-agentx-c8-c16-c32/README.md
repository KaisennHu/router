# Colocated AgentX benchmark

Open `report.html` in a browser for the experiment, analysis and charts; the images are embedded for offline use. `report.md` and the PNGs are also included. `results.json` contains aggregated client and worker metrics. Each concurrency/policy cell is one run. The report is also available in [Router PR #444](https://github.com/vllm-project/router/pull/444).
