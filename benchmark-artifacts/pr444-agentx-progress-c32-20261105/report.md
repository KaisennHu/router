# C32：混部 Progress 候选场景

本报告包含一轮独立的带埋点诊断及 5 轮不带逐请求埋点的性能对照。结果是单次探索，不能代表全部 AgentX 场景；变化比例为新值相对基准的变化，负数不一定是收益。

## 实验条件

- AgentX 原始结构筛选子集：32 个 session、128 个请求，4,620,928 input 和 55,699 output tokens；C32，4 × B300。
- Qwen3-4B-Instruct-2507、BF16、TP1，单 worker HBM KV 96 GiB，HOST 关闭；max model length 196,608、最大批处理 token 数 8,192、每个 worker 最多 16 个运行序列。
- 每个 session 的前 4 个原始请求；按固定规则选 16 个首请求较长的 session 和 16 个较短的 session，C16 首批 16 个中 8 个较长；C32 可同时开始全部 32 个。筛选规则在运行前固定，没有按性能结果筛选。
- AgentInfer 回放；同 agent 间隔缩放为 0，异 agent 间隔沿用回放配置。token ID 根据 session 内的源 hash 重建，不保留跨 session 前缀共享，因而不是对真实 AgentX 整体的代表性测量。
- 5 组各运行一次；Cache 使用默认阈值（cache 0.3，绝对负载差 64，相对 1.5）。每轮重启 worker、预热 Router 和 worker，再清理 worker 前缀缓存；性能测量不启用诊断日志。
- Cache 为 cache-aware；KV 为 kv-aware；P 表示开启 prefill progress（stale-after 5 秒），A 表示开启 session affinity（TTL 1,800 秒）。未标记 P 或 A 的组关闭对应功能。
- 数据子集 SHA-256：`fff1352d3bb7959272a9f5cc31f8bd16c34fad7b8426a7b57cf8e7c76753599f`；Router `b2a1f411d5bb`，vLLM `d16847dafe12`。

### TTFT 均值如何变化

| 对照 | TTFT 变化 ms | worker 排队变化 ms | worker prefill 变化 ms | 差值的残余 ms |
| --- | --- | --- | --- | --- |
| KV → KV+P | -63.69 | -54.28 | -12.82 | +3.42 |
| KV+A → KV+A+P | -2.60 | -3.53 | +4.19 | -3.26 |

残余是客户端 TTFT 均值减去两个 worker 均值后再相减的结果，包含 Router、网络、输出处理等影响；它不是单独采集的阶段耗时，也不证明变化由某一阶段引起。

Router 使用 `(新请求预估 prefill tokens + 在途剩余 prefill tokens) × (在途请求数 + 1)` 作为节点成本；Progress 更新第二项。

诊断组：128 个请求关联成功，账本事件不一致 0 次。在 424 个已确认缓存对账的调度采样点，保留初始预留的剩余量绝对误差均值为 8,939.92 token，使用 Progress 的误差为 3,399.97 token（变化 -61.97%）。
同一条 Progress 开启轨迹中，128 次无绑定候选决策中，42 次的候选剩余量与保留初始预留不同；8 次出现严格排序变化，8 次最低分节点集合改变，6 次旧账本最低分存在并列。该影子计算复用开启 Progress 的实际轨迹，不能当作真实关闭 Progress 的选路或时延。

事件解析／回放相关告警行数（匹配关键词）：Cache 0，KV 0，KV+P 0，KV+A 0，KV+A+P 0。原始日志、逐请求数据、环境采样与完整分位数见各运行目录。

本次使用共享主机；运行期间监控选定 GPU 的外来进程和其他设备活动，单次结果仍可能受共享 CPU、I/O 等因素影响。

## 吞吐和平均 JCT 的差异

KV 和 KV+P 最后一个 session 的完成时间分别是 43.61 s 和 40.35 s；对于 KV+P 中最后完成的那个 session，其在 KV 中完成于 43.61 s。总吞吐使用整轮耗时，而 JCT 均值对 32 个 session 分别取平均，二者可以朝不同方向变化。
该 session 中输出 4,169 token 的请求，TTFT 为 0.41 → 0.42 s，首 token 后到请求完成的时间为 35.19 → 32.03 s（-3.16 s）。这是相同请求的观测值；仅凭这几组数据不能判断变化的具体原因，也不能把变化全部归因于 Progress。
